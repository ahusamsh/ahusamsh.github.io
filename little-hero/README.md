# رحلة البطل

تطبيق PWA عربي لمتابعة روتين الطفل والصلوات والقرآن والنقاط والمكافآت.

- التطبيق: https://ahusamsh.github.io/little-hero/
- صفحة الربط المختصرة: https://ahusamsh.github.io/little-hero/setup.html
- قاعدة البيانات: Google Sheets تُنشأ تلقائيًا بواسطة Google Apps Script.
- يعمل دون اتصال ويحفظ محليًا ثم يزامن تلقائيًا.

## الربط

1. افتح صفحة الربط.
2. انسخ السكربت وافتح Apps Script والصقه.
3. انشر كتطبيق ويب باسمك ولأي شخص.
4. افتح رابط النشر واضغط «فتح التطبيق وربطه تلقائيًا».

لا توجد مفاتيح سرية داخل GitHub، ولا حاجة إلى Supabase أو Vercel.
