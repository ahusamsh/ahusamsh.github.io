# سياسة التغييرات والتحقق
- قبل التعديل: حدد المشكلة والدليل والسلوك المقصود ومعايير القبول وحدود التغيير، وافحص الملفات ذات العلاقة.
- أثناء التعديل: حافظ على أصغر تغيير صحيح والتوافق والسجلات والخصوصية، واتبع درجات خطر `docs/ENGINEERING_PLAYBOOK.md`.
- بعد التعديل: تحقق من العمل بوسيلة تناسب الواقع (اختبار موجود أو فحص مباشر)، راجع diff والمخاطر، وحدث `CHANGELOG.md` مع السبب والنتيجة وما لم يُختبر.
- لا تعتبر التعليمات بوابات CI أو حماية فروع مفعلة دون إثبات من المنصة، ولا تنشر أو تغيّر بيانات إنتاجية بسبب هذه الوثائق وحدها.
