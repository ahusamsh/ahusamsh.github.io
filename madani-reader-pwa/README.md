# القاعدة المدنية — قارئ الكاميرا (مكوّن إضافي)

**الهدف:** دمج القراءة التفاعلية للكتاب الورقي داخل تطبيق آخر، وليس إنشاء منصة تعليمية جديدة.

## واجهة الطالب الوحيدة

1. يضغط **تشغيل الكاميرا**.
2. يقرّب رمز QR الموجود في أعلى الصفحة ليُمسح **مرة واحدة** ويُحفظ رقم الصفحة.
3. يعيد توجيه الكاميرا إلى الصفحة كاملة، ويشير بإصبعه إلى الحرف؛ يشغّل المقطع المرتبط به إذا نجحت المحاذاة البصرية.

لا قوائم صفحات أو إعدادات يدوية أو محرر صوت أو عرض PDF في واجهة الطالب.

## المكونات

- `src/reader-module.js`: الدالة العامة `mountMadaniReader(container, options)`.
- `src/page-vision.js`: QR الحالي ومناطق الترميز.
- `src/visual-matcher.js`: متابعة هندسة الصفحة بعد مسح QR، حتى عند صعوبة إعادة قراءته من مسافة أكبر.
- `src/core.js`: تحويل الإحداثيات وربط مناطق القراءة.
- `src/reader.css`: تنسيق المكون دون اعتماد على هيكل التطبيق المضيف.
- `public/data/pilot-audio.json` و`pilot-media`: محتوى الصفحات الثلاث التجريبية.
- `docs/INTEGRATION.md`: دمج المكون داخل التطبيق الآخر.

## التشغيل والبناء

```bash
npm ci
npm test
npm run build
```

ستجد:
- `dist/index.html`: غلاف لتجربة كاميرا المكون دون منصة كاملة.
- `dist/sdk/madani-reader.es.js` و`dist/sdk/madani-reader.css`: ملفات الدمج داخل التطبيق المضيف.
